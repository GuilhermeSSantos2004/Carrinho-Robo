# Hardware

Documentação elétrica e lista dos componentes realmente usados no protótipo atual.

## Conteúdo

- [`arquitetura/`](arquitetura/README.md): alimentação 3S, GND comum, PWM, pinagem do ESP32, L298N, HC-SR04 e LDR;
- [`componentes/`](componentes/README.md): quatro motores TT, três células 18650, resistores, sensores e peças mecânicas atuais.

A proposta antiga de alimentação com pilhas AA/pack 2S permanece apenas no histórico. Para montagem atual, usar a documentação desta pasta e o firmware `src/codigo.ino`.
