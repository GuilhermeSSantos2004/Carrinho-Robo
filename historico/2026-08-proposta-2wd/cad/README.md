# CAD

Pasta destinada aos modelos mecânicos do carrinho.

- [`STL/`](STL/README.md): arquivos prontos para impressão, separados por versão.

As medidas dos componentes físicos devem ser conferidas antes de publicar a primeira versão imprimível.
