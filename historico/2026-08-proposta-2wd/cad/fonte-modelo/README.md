# Fonte do modelo CAD

Guardar aqui os arquivos editáveis usados para gerar os STL, por exemplo:

- OpenSCAD: `.scad`;
- Autodesk Fusion: `.f3d` ou arquivo exportado do projeto;
- FreeCAD: `.FCStd`;
- Blender: `.blend`;
- Maya: `.ma` ou `.mb`.

O nome deve acompanhar a versão do STL, como `chassi-v0.1.f3d` ou `chassi-v0.1.scad`. Registrar no commit qual software e qual versão foram usados.
