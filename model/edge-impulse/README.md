# Biblioteca Edge Impulse do CP2

Diretório reservado para a biblioteca Arduino/ESP32 exportada do projeto real da
equipe no Edge Impulse.

Após o export, adicionar o pacote e atualizar [`../../docs/CP2_EDGE_IMPULSE.md`](../../docs/CP2_EDGE_IMPULSE.md)
com o nome do arquivo, header, versão e Project ID. Até lá, este diretório vazio
não representa uma biblioteca pronta.
